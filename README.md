# Doximity Integrations

This repository contains code samples to help you get started with using Doximity's APIs.

## Samples

- [`ask-api/`](ask-api/) — an example Python web app (with a JS frontend) that shows how to build a chat app using the Doximity Ask API.
- [`ask-iframe/`](ask-iframe/) — an example Python web app that shows how to embed the full Doximity Ask experience in your product using the iframe integration.
